Core Features

Everything You Need to Monitor the Environment

WeatherIQ combines hardware-grade precision with a polished web dashboard for complete environmental intelligence.

Real-Time Monitoring

Live sensor data streamed every 5 seconds via ESP32 to the backend API, displayed instantly on interactive charts.

Temperature & Humidity

High-precision DHT22 sensor tracks temperature (−40 to +80 °C) and relative humidity (0–100%) with ±0.5 °C accuracy.

Pressure Tracking

BMP280 barometric sensor measures atmospheric pressure (300–1100 hPa), useful for weather forecasting and altitude estimation.

Rain Detection

Capacitive rain sensor instantly detects precipitation events and logs them in the database with timestamps for trend analysis.

Air Quality Index

MQ-135 sensor detects CO₂, ammonia, benzene and other VOCs, providing a composite air-quality index (0–4095 raw ADC).

Automated Alerts

Configurable threshold alerts fire automatically when temperature, humidity or air quality exceed safe operating limits.

How WeatherIQ Works

A simple four-stage pipeline from physical sensors all the way to your browser.

1

Sensors

DHT22, BMP280, Rain and MQ-135 collect raw environmental data every 5 s.

2

ESP32

ESP32 microcontroller reads all sensors and POSTs JSON readings to the backend over Wi-Fi.

3

Backend API

FastAPI validates, persists to MySQL and runs alert-threshold checks in real time.

4

Dashboard

Chart.js-powered dashboard fetches the API and renders live graphs, alerts and device status.
